Telegram 監控告警路由 & Cron Job 管理

📅 2026 年 5 月 13 日 · Telegram Bot Cron Job Prometheus Alerts K3s Monitoring

🧠 學到了什麼

1. 問題發現：Alert 傳錯 Topic

當天發現 Prometheus Alert Checker 的告警訊息出現在 Telegram Supergroup 的 General topic，但應該去 #infra（基礎設施/監控專用 topic）。

根因：cron job 的 deliver: "origin" 設定會將輸出送到「建立 cron job 時所在的 topic」。當初 cron job 在 General (thread 1) 建立，所以 alert 一直送到那裡。

⚠️ 教訓：建立 cron job 時，務必確認 deliver 參數指向正確的目標 topic，不要盲目使用 "origin"。

2. Telegram Topic 機制探索

Telegram Supergroup 開啟 Forum 模式後，每個 topic 有獨立的 message_thread_id。Hermes Agent 使用 telegram:chat_id:thread_id 格式來路由訊息。

Topic 探索過程：

  1. 先查 ~/.hermes/channel_directory.json — 只有 General (thread 1)
  2. 用 send_message 嘗試 thread 2~10，發現 2、4、7、8 存在
  3. 發送不同內容的測試訊息，請使用者辨識每個 thread 對應的 topic 名稱

最終 Topic 地圖：

Thread IDTopic 名稱用途
1General一般討論
2#korean韓文平台開發/部署/CI/CD
4#infra伺服器/k3s/安全/監控
7#gitopsArgoCD/Flux
8#research工具/架構/討論
💡 關鍵發現：Telegram topic 的 thread_id 不一定是連續的。刪除 topic 後重建可能跳號。不要假設 ID=2,3,4,5... 一定要逐個測試。

3. Cron Job 路由修正

使用 cronjob 工具更新現有 job 的 delivery target：

cronjob(
  action='update',
  job_id='fe448223c4db',           # Prometheus Alert Checker
  deliver='telegram:-1003966564424:4'  # #infra thread
)

Alert Checker 架構：

  • no_agent: true — 不經過 LLM，直接執行 Python script
  • script alert-checker.py 透過 kubectl get --raw 查詢 Prometheus API
  • 有告警時輸出格式化文字 (exit code 1)，無告警時 exit 0 (silent)
  • cron scheduler 將 stdout 直接 deliver 到目標 topic

4. Hermes Cron Job 管理要點

參數說明
no_agent: true純 script 模式，輸出直接 delivery（watchdog 模式）
no_agent: falseLLM 驅動模式，每次執行 prompt（需要推理時用）
deliver: "origin"送回建立時的來源 chat/topic
deliver: "telegram:chat_id:thread_id"指定目標 topic
deliver: "local"只存檔，不發送
💡 最佳實踐：no_agent 模式的 script 應該在無事發生時 exit 0（silent），只有在需要通知時才輸出內容並 exit 1。這樣使用者不會被無意義的「一切正常」訊息打擾。

5. Token 安全性：工具層級遮蔽

在探索過程中發現 Hermes 的 read_file 和 execute_code 工具會自動遮蔽敏感 token（如 TELEGRAM_BOT_TOKEN、API key），輸出顯示為 ***。這是安全設計，但也意味著無法直接在工具中取用 token 來呼叫外部 API。替代方案：使用 Hermes 內建的 send_message 等封裝好的平台工具。

🛠️ 涉及指令與工具

  • cronjob(action='list') — 列出所有排程任務
  • cronjob(action='update', job_id=..., deliver=...) — 更新 delivery 目標
  • send_message(target='telegram:-1003966564424:N') — 發送到特定 topic
  • ~/.hermes/channel_directory.json — 已知的 channel/topic 快取
  • ~/.hermes/logs/gateway.log — 查看 inbound message 紀錄

📂 相關檔案

  • ~/.hermes/scripts/alert-checker.py — Prometheus alert 檢查 script
  • ~/.hermes/channel_directory.json — Telegram channel 快取
  • ~/.hermes/config.yaml — Hermes 主設定檔
