💡 Next.js 16 standalone 模式輸出

next.config.ts 設定 output: 'standalone' 後，next build 會產生自給自足的 .next/standalone 目錄，不需依賴專案目錄即可執行

# next.config.ts
export default {
  output: 'standalone',
}

💭 standalone 模式把 runtime 依賴打包進 .next/standalone，Docker 多階段建置只需複製這個目錄 + public + .next/static，大幅縮小 image

Next.jsstandaloneDocker部署

💡 PM2 管理 Next.js 進程

用 PM2 process manager 管理 Node.js app，支援自動重啟、log 管理、開機啟動

pm2 start npm --name korean-learning -- start
pm2 save
pm2 startup

💭 PM2 確保 Next.js server crash 後自動重啟，比 nohup/screen 更可靠；ecosystem.config.cjs 可宣告式定義多個 app

PM2Next.jsprocess manager部署

💡 Nginx reverse proxy 到 Next.js（port conflict）

Nginx 監聽 8080 port（80 被 Hermes gateway 佔用），反向代理到 localhost:3000

# /etc/nginx/sites-available/korean-learning
server {
    listen 8080;
    server_name shawnlin.online;
    location / {
        proxy_pass http://localhost:3000;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
    }
}
sudo ln -s /etc/nginx/sites-available/korean-learning /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx

💭 80 port 被 Hermes gateway 佔用無法綁定，暫時用 8080；後續 Cloudflare 需要 Origin Rule 把流量導向 8080, 但 free plan 沒有這個功能

💡 Cloudflare DNS + Proxy（orange cloud）

從 GoDaddy 轉移 DNS 到 Cloudflare，設定 A record 和 CNAME，開啟 proxy 做 TLS termination

curl -X POST "https://api.cloudflare.com/client/v4/zones/ZONE/dns_records" \
  -H "Authorization: Bearer TOKEN" \
  --data '{"type":"A","name":"@","content":"43.167.10.119","proxied":true}'

💭 GoDaddy DNS 有錯誤改用 Cloudflare free tier；Proxy 模式隱藏 origin IP + 免費 TLS 憑證，不需管理 Let's Encrypt

CloudflareDNSTLSproxy

💡 Cloudflare Error 522：origin port 問題

Cloudflare 預設走 80/443 連 origin，但 80 port 被 Hermes 佔用，導致 Error 522

💭 Free plan 沒有 Origin Rules，無法 redirect 到 8080。替代方案：Workers rewrite port，或把 Hermes 移到其他 port 釋放 80

CloudflareError 522debuggingport

💡 Self-signed SSL vs Cloudflare TLS

自簽憑證只適合內網測試；對外服務用 Cloudflare Flexible SSL 處理 TLS，origin 跑 HTTP 即可

sudo openssl req -x509 -nodes -days 365 -newkey rsa:2048 -keyout /etc/ssl/korean-learning.key -out /etc/ssl/korean-learning.crt

💭 Cloudflare Flexible SSL：user↔Cloudflare 加密，Cloudflare↔origin HTTP，不需 origin 管理憑證

SSLTLSCloudflare憑證

💡 GitHub repo + PAT 認證設定

建立 repo shawnlin0125/korean-learning，用 Personal Access Token 做 HTTPS git 操作

git config --global user.name "shawnlin0125"
git config --global user.email "shawnlin0125@gmail.com"
git remote add origin https://github.com/shawnlin0125/korean-learning.git

💭 GitHub 已停用密碼認證，push/pull 需 PAT 或 SSH key；PAT 設 repo scope 最少權限

GitHubgitPAT認證

💡 shadcn/ui + TailwindCSS + zustand 技術棧選擇
